# RGL-OA智能归档助手 安装与更新教程

适用于 Windows 10 / 11（64 位）。程序是绿色版：不需要安装 Java、数据库或其他软件，解压后双击就能用。

- 下载地址：<https://github.com/tonightrrrrrr/RGL-OA/releases>
- 每个版本更新了什么：[CHANGELOG.md](../CHANGELOG.md)，程序里侧栏的“版本更新”也能看到

---

## 一、第一次安装

### 方式 A：下载安装包（推荐）

1. 打开 [Releases 页面](https://github.com/tonightrrrrrr/RGL-OA/releases)，在最新版本下面的 **Assets** 里下载 `OA-Archive-Agent-v版本号-win64.zip`（约 170 MB）。
2. （可选）核对文件完整：在下载目录打开 PowerShell，运行下面的命令，结果应和同一版本的 `.sha256` 文件里的值一致。
   ```powershell
   Get-FileHash .\OA-Archive-Agent-v1.5.2-win64.zip -Algorithm SHA256
   ```
3. 右键 zip →“全部解压缩”，解压到一个**有写入权限**的文件夹，例如 `D:\RGL`。解压后的结构：
   ```text
   D:\RGL\OA-Archive-Agent\
     OA-Archive-Agent.exe         双击启动
     OA-Archive-Agent-Debug.exe   启动有问题时用，会显示日志窗口
     示例文件\                    赛题的 10 份示例（v1.5.1 起另有“反面案例”）
     app\  runtime\               程序本体和内置 Java，不要改动
   ```
4. 双击 `OA-Archive-Agent.exe`。第一次启动约 10 秒，之后浏览器会自动打开程序界面，右下角托盘出现 RGL 图标。
   - 如果 Windows 提示“已保护你的电脑”，点“更多信息”→“仍要运行”。程序没有购买代码签名证书，所以会出现这个提示。
5. 第一次打开会显示欢迎公告。到“导入识别”页，选择 `示例文件` 文件夹 →“开始识别”→“预览并归档”，就能看到完整流程。

**数据存在哪**：程序在 exe 旁边自动建一个 `data` 文件夹，存放数据库、模板、台账、日志和 AI 设置。如果程序所在的文件夹不能写入（比如放在 `C:\Program Files`），数据会改存到 `%LOCALAPPDATA%\OA-Archive-Agent\data`。

**退出程序**：关掉浏览器页面不会退出。要退出，请右键托盘里的 RGL 图标 →“退出”。

### 方式 B：从源码构建（开发者）

需要 JDK 17、Maven 3.8+、Git。Node.js 和 pnpm 由 Maven 自动下载，不需要自己装。

```bash
git clone https://github.com/tonightrrrrrr/RGL-OA.git
cd RGL-OA
mvn package -DskipTests
java -jar target/oa-archive-agent.jar
```

打开 <http://127.0.0.1:18080> 即可使用。要打出和 Releases 一样的绿色版：

```powershell
powershell -ExecutionPolicy Bypass -File packaging/package.ps1
```

打包脚本会自动下载 Temurin 17 运行时（先走清华镜像），产物在 `release/` 目录。

## 二、后续更新

### 怎么知道有新版本

- 程序启动后会在后台连 GitHub 检查一次（每天最多一次）。有新版本时，顶栏出现绿色的“新版本 vX.X”按钮，并弹出一次更新说明。
- 也可以在“系统设置 → 检查更新”里手动检查，或者关闭自动检查。
- 检查时只请求 GitHub 上的版本信息，不发送任何台账或文件数据。

### 方式 A：用安装包升级（推荐）

1. 在更新提示里点“下载新版本”，或到 Releases 页面下载新的 zip。
2. **先退出旧版**：右键托盘图标 →“退出”。旧版还在运行时，文件会被占用，覆盖不了。
3. （建议）把旧版的 `data` 文件夹复制一份做备份。
4. 把新 zip 解压到**原来的文件夹**，提示有同名文件时选“替换”。zip 里没有 `data` 文件夹，所以你的数据库、模板、台账都会保留。
5. 双击 `OA-Archive-Agent.exe`，会弹出“RGL 已更新到 vX.X”的公告。

如果想把新版放到别的文件夹，把旧版的 `data` 文件夹整个复制到新版 exe 旁边即可。

**图标还是旧的**：Windows 会缓存图标。运行下面的命令刷新一下，或者重启资源管理器：

```powershell
ie4uinit.exe -show
```

### 方式 B：从源码更新（开发者）

```bash
cd RGL-OA
git pull
mvn package -DskipTests
```

要切到某个指定版本：`git checkout v1.5.2`（所有版本见 `git tag`）。

### 回退到旧版本

退出程序，到 Releases 页面下载旧版本的 zip，按“用安装包升级”的步骤覆盖即可，数据会保留。新版本可能对数据库做了升级，如果旧版打开有问题，请恢复升级前备份的 `data` 文件夹。

## 三、没有联网时

- 识别、OCR、归档、台账、模板、导出等所有功能都不需要联网，断网照常使用。
- 联网检查更新在后台进行，连不上 GitHub 时只在“系统设置 → 检查更新”里显示“未联网”，不会弹窗，也不会报错。
- 只有两样东西需要联网：检查新版本，以及 AI 助手（还要你自己配置模型接口）。
- 断网的电脑要升级时，在能上网的电脑上下载 zip，拷过去按上面的步骤覆盖即可。

## 四、常见问题

| 问题 | 处理 |
| --- | --- |
| 双击后没反应，或者浏览器显示“无法连接到程序后台” | 看托盘里有没有 RGL 图标；没有的话运行 `OA-Archive-Agent-Debug.exe` 查看报错，日志在 `data\logs` |
| 提示程序已经在运行 | 已经有一个在运行了，双击托盘图标打开界面即可 |
| 端口 18080 被占用 | 程序会自动换到 18081–18099 中的空闲端口，不用处理 |
| GitHub 下载很慢 | 可以换个时间再下载，或者在能访问 GitHub 的电脑上下载后拷过来 |
| 升级后数据不见了 | 检查是不是解压到了新的文件夹：把旧文件夹里的 `data` 复制过来即可 |
