# RGL-OA智能归档助手 使用手册

适用版本：v1.9.1　适用系统：Windows 10 / 11（64 位）

RGL 把一批办公文件（Word、Excel、PDF、图片）自动识别出**部门、文件类型、日期和标题**，按模板统一重命名，复制到归档目录的“年份 / 部门 / 类型”文件夹里，同时生成可搜索、可导出 Excel 的文件目录台账。全程离线运行，内置 OCR，可以识别扫描件和手机拍的照片。

安装、更新、回退旧版的详细步骤见《安装与更新教程》。

## 一、五分钟上手

1. 解压安装包到有写入权限的文件夹（如 `D:\RGL`），双击 `OA-Archive-Agent.exe`。约 10 秒后浏览器自动打开程序界面，右下角托盘出现 RGL 图标。
2. 在“导入识别”页选“导入文件夹”，点输入框右边的“选择…”，选安装目录里的 `示例文件`。
3. “归档目录”默认是“文档\OA归档”，可以改成任意文件夹（不能是导入的文件夹本身或它的子文件夹）。程序会记住上次用的目录。
4. 点“开始识别”。10 份示例约 2 秒处理完，状态都是“待归档”。
5. 点“预览并归档”，确认新文件名和目录后点“确认归档 N 个文件”。
6. 打开归档目录，可以看到 `2026\人力资源部\通知\人力资源部_通知_2026-03-15_关于张明等同志职务任免的通知.docx` 这样的文件，以及总台账 `文件目录台账.xlsx`。

> 关掉浏览器页面不会退出程序。要退出，请右键托盘图标 →“退出”。再次双击 exe 会直接打开已在运行的界面。

## 二、界面一览

| 侧栏菜单 | 用途 |
| --- | --- |
| 导入识别 | 选择文件夹或上传文件，查看识别进度和结果，预览并归档、撤销、重试失败的文件 |
| 待确认 | 所有批次里需要人工确认的文件，对照原文修正部门、类型、日期、标题 |
| 台账 | 已归档文件的目录台账：关键词搜索、筛选、排序、打开文件、导出 Excel |
| 模板设置 | 企业自定义部门、文件类型、命名规则、目录规则、档号规则和识别阈值 |
| AI 助手 | 可选。连接 OpenAI 兼容的大模型后，用对话查询台账、修正识别结果 |
| 系统设置 | 默认归档目录、OCR 模型选择与对比、OCR 自检、检查更新、数据目录位置 |
| 版本更新 | 每个版本的更新内容；默认只展开最新版本，点标题展开、收起，也可以“全部展开” |

## 三、导入文件

**按文件夹导入（推荐）**：会递归扫描子文件夹（默认最多 10 层），原文件只读不改。

**上传文件**：切到“上传文件”，把文件或文件夹拖进虚线框，或点击选择，可以一次选多个。适合文件不在本机固定位置的情况。

支持的格式：Word（doc、docx、wps）、Excel（xls、xlsx、et）、PDF、图片（jpg、png、bmp、tif、gif、webp）、txt、rtf、odt、ods。其他格式也会尝试读取内容。

导入时自动跳过、并在批次信息里列出原因的文件：

| 情况 | 说明 |
| --- | --- |
| Office 临时文件 | 以 `~$` 开头，Word、Excel 打开文件时生成 |
| 隐藏文件、系统文件 | 以 `.` 开头、带隐藏属性，或 Thumbs.db、desktop.ini |
| 空文件 | 0 字节 |
| 超过大小上限 | 默认单个文件 200 MB |

单次导入最多 5000 个文件。选错了文件夹（例如整个磁盘）时会直接提示，不会开始处理。文件多时请按部门或年份分批导入。

## 四、识别结果

每个文件处理后进入下面一种状态：

| 状态 | 含义 | 怎么处理 |
| --- | --- | --- |
| 待归档 | 部门、类型、日期的置信度都达到阈值（默认 75%） | 直接归档 |
| 待确认 | 至少一项没把握，“原因”列写明是哪一项 | 到“待确认”页修正，或勾选“同时归档待确认的文件” |
| 重复 | 内容和台账里已有的文件，或同一批次里的另一个文件完全相同（按 SHA-256 判断，和文件名无关） | 默认不归档 |
| 失败 | 文件损坏、设置了密码、格式不支持等，原因列写明 | 修好文件后点“重试”；或“移除”这条记录（原文件不受影响） |

**识别依据**：点文件名打开详情，可以看到每个字段是根据哪一行文字判断的（落款、抬头、标题、文件名、正文关键词）、候选值和得分、原文预览和处理步骤。

**文件名没有含义也能识别**：像 `扫描件001.pdf`、`IMG_2045.jpg` 这样的文件，程序会读正文和落款；图片和扫描版 PDF 自动做 OCR。

**简历**：识别为“简历”类型，按应聘岗位推测部门（如 Java 开发工程师 → 研发部），推测出来的部门一律进入待确认。岗位和部门的对应关系可以在“模板设置 → 岗位规则”里改。

## 五、人工确认

1. 打开“待确认”页，点文件打开详情，对照原文预览和识别依据。
2. 修改部门、类型、日期、标题，点“确认 / 保存修正”。部门和类型只能从模板里选；识别结果本来就对的，直接点这个按钮确认。
3. 确认后文件变为“待归档”，新文件名按修正后的内容生成，台账里标记为“人工修正”。

已经归档的文件不能直接修改，要先撤销这个批次。

## 六、归档

- **预览并归档**：先列出每个文件的新文件名、目标目录和冲突提示，确认后才写文件。默认只归档“待归档”的文件；勾选“同时归档‘待确认’的文件”会一起归档。
- **归档选中**：在列表里勾选文件后只归档这些。
- 归档是**复制**，原文件不动（模板里可以改成“移动”）。每个文件先写成临时文件、校验 SHA-256 后再改名，校验不通过就删掉临时文件并报错，不会留下半个文件。
- 新文件名重名时自动加“（2）”“（3）”；目标位置已有内容相同的文件时跳过。文件名里 Windows 不允许的字符（`/ \ : * ? " < > |`）自动换成全角字符。
- 每个文件分配一个档号，默认格式 `2026-RS-TZ-0001`（年份-部门代码-类型代码-流水号），档号不会重复。
- 归档后在归档目录根部自动生成或更新总台账 `文件目录台账.xlsx`。

默认规则（可以在模板设置里改）：

| 项 | 默认 | 示例 |
| --- | --- | --- |
| 目录 | `{年}/{部门}/{类型}` | `2025/法务部/合同/` |
| 文件名 | `{部门}_{类型}_{日期}_{标题}` | `法务部_合同_2025-10-01_原材料采购框架合同.pdf` |
| 档号 | `{年}-{部门代码}-{类型代码}-{序号4}` | `2025-FW-HT-0001` |

## 七、OCR 模型

扫描件、图片和没有文字层的 PDF 用 OCR 识别。“系统设置 → OCR 模型”里内置三套离线模型，点“使用这个模型”立即生效，不用重启：

| 模型 | 适合 | 特点 |
| --- | --- | --- |
| PP-OCRv6 small（默认，推荐） | 扫描件、手机照片、手写体多 | 准确率最高，生僻字、繁体也能认；比 PP-OCRv4 稍慢 |
| PP-OCRv6 tiny（极速） | 大批量扫描件、配置较低的电脑 | 最快、最小；只认 6904 个常用字，手写体不如 small |
| PP-OCRv4 mobile（经典） | 要和 v1.9 及以前导入的结果保持一致 | 以前一直使用的模型 |

拿不准选哪个时，在卡片下方“用自己的图片对比”上传一张自己公司的扫描件，三套模型分别识别，看哪个认得最全。切换只影响之后导入的文件。

## 八、撤销、删除和回档

| 操作 | 做什么 | 原文件 | 归档出去的文件 | 台账 |
| --- | --- | --- | --- | --- |
| 撤销本批次 | 把这个批次归档出去的文件收回 | 不动 | 删除（归档后被改过的保留并提示） | 移除 |
| 删除记录 | 删除批次在程序里的记录 | 不动 | 不动 | 已归档的保留 |
| 移除文件 | 从批次里去掉一个还没归档的文件 | 不动 | — | — |
| 回档 | 撤回最近一次归档、撤销、删除、模板修改或 AI 助手的操作，只能回一步 | 不动 | 恢复到操作前 | 恢复到操作前 |

**程序中途被关闭**（断电、在任务管理器里结束）：下次启动时，没处理完的文件会标为“失败”，原因写“程序在处理过程中被关闭”。在导入识别页点“重试失败的文件”即可整批重新处理。

## 九、台账

- **关键词搜索**：在标题、原文件名、新文件名、关键词、档号、合同编号、文号、甲乙方、部门、类型里查找。多个词用空格分隔，表示同时包含。输入后自动检索。
- **筛选**：部门、类型、日期范围、格式、识别方式（自动 / 人工确认 / 人工修正）。
- 点列标题排序；点文件名用系统程序打开文件，或打开所在文件夹。
- **导出 Excel**：默认导出全部搜索结果；勾选后可以“只导出勾选的 N 条”（一次最多 1000 条）。导出的表格带筛选按钮，“归档路径”列可以直接点击打开文件。

## 十、模板设置（企业自定义 OA 模板）

模板决定了“认哪些部门、哪些类型，怎么命名，放到哪里”。内置的“默认模板”不能修改和删除，可以复制一份再改。

| 设置 | 说明 |
| --- | --- |
| 部门 | 名称、代码（用于档号）、别名（如“人事部”算作“人力资源部”）、关键词 |
| 文件类型 | 名称、代码、标题后缀（如“纪要”“会议纪要”）、关键词 |
| 关键词规则 | 正文出现某些词时加分，如出现“考勤”倾向人力资源部 |
| 岗位规则 | 简历的应聘岗位对应哪个部门 |
| 命名、目录、档号规则 | 用 `{部门}` `{类型}` `{日期}` `{标题}` `{年}` `{月}` `{原文件名}` `{部门代码}` `{类型代码}` `{序号4}` 等变量组合 |
| 识别阈值 | 置信度低于它就进入待确认。调高更稳妥、待确认更多；调低更省事、出错风险更大 |
| 归档方式 | 复制（默认）或移动 |

编辑时右侧实时显示示例文件按新模板识别、命名的结果，“智能检查”会指出规则冲突、重名风险等问题，“阈值顾问”会根据已导入的文件给出建议值。模板可以导出成 JSON 发给其他电脑导入。导入时选用哪个模板，在导入识别页的“模板”下拉框里选。

## 十一、常见问题

| 问题 | 解决 |
| --- | --- |
| 打开页面卡住、内容不显示 | 刷新一次页面（F5）。v1.9 起页面不再使用过期的缓存，正常不会再出现 |
| 每次打开都弹“发现新版本” | 当前不是最新版。下载新版本覆盖后就不再提醒；不想联网检查可以在“系统设置 → 检查更新”里关闭自动检查 |
| 双击 exe 没反应 | 程序可能已在运行，看右下角托盘；或运行 `OA-Archive-Agent-Debug.exe` 查看日志 |
| 页面显示“无法连接到程序后台” | 程序已退出，重新双击 exe |
| 文件“处理失败：PDF 设置了打开密码” | 去掉密码后重新导入 |
| 文件“处理失败：文件无法解析” | 文件已损坏或只下载了一半，换一份完好的文件 |
| 扫描件识别不准 | 到“系统设置 → OCR 模型”换成 PP-OCRv6 small，或用“对比”看哪套模型认得最好；图片太糊、太小会影响识别 |
| 提示“超过单次导入上限” | 换一个更具体的文件夹，分批导入 |
| 提示“拒绝来自其他网站的请求” | 有其他网页试图操作本程序，已被拦截。请只通过 `http://127.0.0.1:端口` 打开程序 |
| 数据存在哪 | exe 旁边的 `data` 文件夹（数据库、模板、日志、AI 设置）；升级覆盖时会保留 |
